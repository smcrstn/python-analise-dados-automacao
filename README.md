Python para Análise de Dados e Automação

Sobre o projeto

Este repositório apresenta um caderno temático desenvolvido para estudar **Python aplicado à análise de dados e automação de processos**.

O projeto foi desenvolvido como parte de um desafio da **DIO**, utilizando o NotebookLM como ferramenta de pesquisa, organização e consolidação do conhecimento.

Além de atender à proposta do desafio, este material foi pensado para servir como **material de consulta profissional futura**, permitindo revisar conceitos, exemplos, ferramentas e aplicações práticas de Python em projetos de análise de dados, automação e processos relacionados à logística e gestão de estoque.

Objetivos

* Desenvolver e consolidar conhecimentos fundamentais de Python;
* Compreender a aplicação de Python na análise e tratamento de dados;
* Conhecer bibliotecas utilizadas no mercado, como Pandas e OpenPyXL;
* Explorar automação de tarefas e integração com APIs;
* Relacionar os conhecimentos de programação com situações práticas de logística e controle de estoque;
* Utilizar ferramentas de IA de forma estruturada para pesquisa e aprendizagem;
* Criar um material organizado que possa ser utilizado como referência para estudos e projetos profissionais futuros.

Tecnologias e ferramentas

* **Python** — linguagem utilizada no desenvolvimento dos exemplos;
* **VS Code** — ambiente utilizado para desenvolvimento e testes;
* **Pandas** — tratamento e análise de dados;
* **OpenPyXL** — criação e manipulação de arquivos Excel;
* **Requests** — comunicação com APIs;
* **Git e GitHub** — versionamento e organização do projeto;
* **NotebookLM** — pesquisa, organização e consolidação do conteúdo estudado.

Estrutura do projeto

O repositório está organizado para apresentar não apenas o resultado final, mas também o processo de pesquisa e aprendizagem:

* `fontes/` — fontes utilizadas na pesquisa e disponibilizadas no NotebookLM;
* `engenharia-de-prompts/` — prompts utilizados, testes, dificuldades e melhorias realizadas;
* `miniguia/` — resumo estruturado, conceitos e glossário para consulta futura;
* `projeto-pratico/` — exemplo de aplicação de Python em automação e controle de estoque;
* `apresentacao/` — material de apresentação desenvolvido durante o projeto.
